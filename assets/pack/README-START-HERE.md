# Anya Sarre - Proposed Identity & Hero Asset Pack

Prepared by Wesley Quinn / Built By Wes / 13 November 2026.
Independent website concept for cold outreach. This is not an approved rebrand.

## Recommendation
Direction 01, Sculpted Masthead, paired with hero 01, Backstage / Monochrome.
For a more playful first impression, use hero 02, Jewellery / Pink.
Use one chosen hero, not all ten on a home-page carousel.

## Contents
- 01-Identity: primary, compact and stacked wordmarks, dark/light/pink SVG and transparent PNG; three lettering explorations; palette and CSS tokens.
- 02-Heroes: ten numbered choices. Each has a separate desktop and mobile composition, JPEG and WebP web exports, plus PNG masters.
- 03-Previews: four-page identity lookbook, identity overview, three-direction lettering sheet, all-ten hero contact sheet, and separate wordmark composition studies.
- 04-Handover: two-page handover, per-image crop/focal guidance, exact asset inventory, generation prompts and contrast ratios.
- 05-Supporting-Graphics: open frame, editorial rule, curved tail. Use sparingly; one gestural motif per composition.
- 06-Fonts: verified Bricolage Grotesque and DM Sans variable TTF and WOFF2, original OFL licences and self-host CSS.

## Vector and raster integrity
All delivered wordmark SVGs contain genuine vector paths and no embedded images or live text. Direction 01 and 03 lettering is original path artwork. Direction 02 is outlined Bricolage Grotesque with condensed proportions; it is an exploration, not the recommended identity. PNG/PDF presentation sheets and all photographic assets are raster. The wordmark PNGs have real transparent alpha, including the light variants intended for dark surfaces.

## Exact dimensions
Desktop JPEG/WebP: 1774 x 887px. Mobile JPEG/WebP: 1120 x 1400px. No image was upscaled for these web exports. Mobile export normalisation removes only an approximately one-pixel edge from the native generated 4:5 master. PNG masters retain their native dimensions; read asset-inventory.csv for every file. Wordmark PNGs are 3000px wide with proportional height; SVG artwork scales without a pixel limit.

## Image provenance and approvals
01-05 are source-based AI reconstructions. 01 uses the earlier preferred B&W hero as its starting point and replaces ambiguous hands with two connected, invented assistants; the original cup and extra disconnected hands are removed.
06-07 are extensive TV-derived reconstructions. They must not be represented as untouched stills or documentary photographs from the broadcasts. Their reconstructed rooms and details are invented.
08-09 are newly imagined portraits based on Anya's supplied identity references; 10 is a newly generated still life. These are concept options, not commissioned photographs or proof of an actual place, styling engagement, product endorsement or team.
All directions and photos need Anya's approval before publication, including likeness, jewellery detail and permission to use the source photographs. The small references do not establish unseen detail reliably. Option 05 has the weakest identity reference (279 x 352px); prefer a high-resolution original before public use. Replace any reconstruction whose face/details Anya does not approve with licensed original photography.
Official publication mastheads and TV network logos are intentionally absent; source them as approved official assets during the website build. The pre-existing Styled by Anya seal was assessed but is not redrawn or included as a new mark.

## Implementation
Use the desktop and mobile file from the SAME option number. Focal percentages identify the point in the image to keep visible, not a CSS object-position value that can be copied blindly. Prefer showing the delivered aspect ratio without further cropping. If a builder forces a different ratio, inspect it at each breakpoint and protect the listed crop priority. Put supporting copy below the mobile photograph when the clear top field is insufficient.
Use SVG for the wordmark in the website. Accessible name: Anya Sarre. Give a decorative logo empty alt text only when an adjacent visible name already supplies the same meaning. Check text contrast on the actual final photograph; palette contrast ratios do not guarantee readable overlays.
